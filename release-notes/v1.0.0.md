The first release of TV Thing for Windows, a Windows port of TV Thing 3.1.0 by Ben Markowitz (https://github.com/bpmarkowitz/tvthing). Live TV on a Spotify Car Thing running Bridgething, with the sound on your Windows PC.

## Install

1. Download TVThing-Windows-1.0.0.zip below.
2. Install it in the Bridgething desktop app as a local app and approve its permissions.
3. For streams the Car Thing can't play directly, install FFmpeg 7.1 or later with `winget install Gyan.FFmpeg`, then restart Bridgething.

## Changes from TV Thing

- Finds ffmpeg.exe on PATH and in the winget, Scoop, Chocolatey and C:\ffmpeg\bin locations.
- Runs FFmpeg directly. The extension only asks to run ffmpeg.exe, not /bin/sh or pkill.
- Writes conversions to %TEMP%\TVThing-Transcodes, and builds proper file URLs for Windows paths, which converted channels need.
- The relay follows file: links only in FFmpeg's own output, never in a playlist from the internet.
- Its own app id and port (17849), so it can be installed beside TV Thing. Channels move over with Export and Import in settings.

## Known limits

- Tested on Windows in CI (build, unit tests, and a full FFmpeg conversion with the manifest's permissions), but not yet on a real PC with a Car Thing. Please open an issue with the log from http://127.0.0.1:17849/api/v1/log if something doesn't work.
